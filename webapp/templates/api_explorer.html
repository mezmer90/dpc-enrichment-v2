GET /api/enrichment/status

Get current enrichment run status including progress, statistics, and run details.

Click "Test Endpoint" to see response...
Example Response:
{ "current_run": { "id": 1, "status": "running", "total_practices": 2763, "successful": 150, "failed": 5, "success_rate": 96.8 } }
POST /api/enrichment/start

Start a new enrichment run with optional limit and worker configuration.

Request Body (JSON):
limit (number, optional) - Number of practices to enrich
max_workers (number, optional) - Max concurrent workers (default: 6)
Click "Test Endpoint" to see response...
POST /api/enrichment/pause

Pause the currently running enrichment process.

Click "Test Endpoint" to see response...
POST /api/enrichment/resume

Resume a paused enrichment process.

Click "Test Endpoint" to see response...
POST /api/enrichment/stop

Stop the currently running or paused enrichment process.

Click "Test Endpoint" to see response...
GET /api/practices

List practices with pagination, filtering, and search.

Query Parameters:
page (number, optional) - Page number (default: 1)
per_page (number, optional) - Items per page (default: 50)
status (string, optional) - Filter by status (pending, completed, failed)
search (string, optional) - Search by name or ID
Click "Test Endpoint" to see response...
GET /api/practices/{id}

Get detailed information about a specific practice including enriched data.

POST /api/admin/reverse-geocode

Convert lat/long coordinates to addresses for practices missing address data (processes up to 100 at a time).

Request Body (JSON):
password (string, required) - Admin password
limit (number, optional) - Max practices to geocode (default: 100)
Click to test reverse geocoding (will take ~10 seconds for 10 practices)...
